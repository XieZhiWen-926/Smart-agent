# ==============================================
# 智扫通智能客服 v2 - 后端依赖（版本已锁定，勿随意升级）
# ==============================================
# 安装：pip install -r requirements.txt
#
# 【为什么必须锁死版本？】
# 本项目 Agent 用的是 LangChain 1.x 的「中间件风格」新 API
# （langchain.agents.create_agent），它与 0.3.x 的旧 API 完全不兼容：
#   代码写 create_agent(...)  →  装了 langchain 0.3.x 会直接
#   ImportError: cannot import name 'create_agent' from 'langchain.agents'
#
# 更麻烦的是「跨包版本对齐」：langchain / langchain-core / langchain-community /
# langchain-chroma / langgraph / langchain-text-splitters 六个包互相约束，
# 只要有一个越界，pip 就会抛 ResolutionImpossible，镜像根本构建不出来。
#
# 下面这一组是经过 pip 实际解析验证、可共存的最小自洽组合（Python 3.11）。
# 修改任何一行前，请先跑一遍：
#   pip install --dry-run -r requirements.txt
# 确认没有冲突再改。
# ==============================================

# ==============================================================
